# Google Business Profile — Post Drafts

These are **ready-to-post drafts** for The Proud Paintbrush Google Business Profile. They are intentionally **not** part of the website build — publishing happens manually in the GBP dashboard (or via the existing Zapier connection).

How to use each file:
- **Post type** — which GBP post format to use ("What's new", "Offer", or "Event").
- **Photo** — a suggested image (filenames refer to `public/images/migrated/`; upload the actual photo when posting).
- **Body** — paste into the post text. Each is kept under GBP's ~1,500-character limit.
- **Button / CTA** — the action button to attach (Call / Book / Learn more) and the link.

Cadence suggestion: post 1–2 per week, rotating project spotlights, community stories, and seasonal reminders. Always end with a clear call to action and the phone number (832) 605-0493.
